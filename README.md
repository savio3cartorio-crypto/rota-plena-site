# Rota Plena

Portal brasileiro de caravanismo de Sávio Antonio Americano: mapa de pontos, 77 roteiros, planejador, ferramentas, revista e diários de bordo.

- Tecnologia: Next.js (exportação estática), React, Leaflet/OpenStreetMap.
- Hospedagem: Hostinger (plano Premium, site estático em `public_html`).
- Conteúdo: `app/data/` (artigos, diários públicos, rotas, cidades, notícias) e `public/pontos-da-rota.csv` (pontos do mapa).

Como atualizar e publicar: veja `PUBLICAR.md`.
